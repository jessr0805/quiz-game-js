# Quiz Game (JAVASCRIPT)

A JavaScript-based Quiz Game for people who want to test their knowledge, have fun, or check out what basic JavaScript code looks like.

## Cool Features

* **Multiple Choice Questions**
* **Answer Validation**
* **Score Tracking**
* **Interactive Quiz Interface**
* **Quiz Completion Screen**
* **Correct and Incorrect Answer Feedback**

## How to Run It

Ensure a web browser is installed.

To run the quiz directly in your browser,

* Clone the repository
* Navigate to the repository
* Open `index.html` in your browser
* Play the quiz
